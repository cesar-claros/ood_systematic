## Gate 1: Delta-baseline semantics (pinned)

Executable form: `make_projection_targets.py`, which imports the paper's own generator (`projection_filtering_analysis.py`) so the semantics are identical by construction, and writes `projection_targets_dev.csv` (120 family-variant rows, 29 significant improvements).

1. Source data: `scores_risk/scores_AUGRC_MCD-False_{Conv,ViT}_{source}.csv` (plain files, MCD-False; AUGRC x1000, run-averaged rows per paradigm, dropout, reward, method).
2. Pool restriction: Conv rows filtered to `model == "confidnet"`; ViT files are single-paradigm (`modelvit`) and used whole.
3. Pairing unit: (paradigm, dropout, reward) x source x OOD evaluation column, with the per-source OOD column lists of the generator; the ID `test` column is excluded.
4. Delta = AUGRC(base) - AUGRC(variant); positive means the variant improves (AUGRC is lower-better). `delta_augrc` is the mean over paired cells; `median_diff` and `n_total` are carried for transparency.
5. Baselines per family: the raw (unprojected) method for every family except PCA RecError and KPCA RecError, which exist only under projection and are baselined at their own `global` variant.
6. Significance: two-sided Wilcoxon signed-rank on the pooled paired deltas, alpha = 0.05, no multiplicity correction (matching the paper's generator). `significant_improvement` = significant AND mean delta > 0. Held-out scoring adds null baselines and multiplicity control per X6 section 8; the dev targets deliberately mirror the paper instead.
7. Variant coverage: `global`, `class`, `class pred`, `class avg` as available per family. Tier rules cover global / class pred / class avg; the `class` variant (max-over-class reconstruction, unrouted) is scored with the class-pred rule minus the routing screen.
8. Thin support after the paradigm filter is visible in `n_total` (e.g. VGG13 Maha rows rest on 8 paired cells); rows with `n_total` < 16 should be read with that in mind.
9. `projection_targets_dev.csv` supersedes the mixed-paradigm `projection_targets.csv` for all campaign scoring; the old file stays as the historical paper-wide table.

**Flag resolved (2026-08-08): the plain files are the source of record.** The `_fix-config` variants are the hyperparameter-locked exports of `retrieve_scores.py --fix-config` (every (dropout, reward) slice retained; built for the intervention dose-response protocol and the NC-predictor Track 1, not for the projection analyses). Empirical verification: recomputing the mixed-paradigm Conv deltas from the plain files reproduces the paper's projection table to rounding on all four reference cells (Maha global +24.14 vs +24.1; PCA RecError class pred +38.64 vs +38.6; Maha class pred +18.66 vs +18.7; pNML class pred +6.73 vs +6.73), while the fix-config files give materially different values (+13.62, +28.22, +20.77, +6.82). The stale README stage-3 note claiming projection analyses consume fix-config was corrected the same day.

**Held-out ResNet18 semantics (pinned 2026-08-08, revised same day):** `scores_risk_resnet18/` contains only `_fix-config` exports and the pool is single-run (`run1` per config; confidnet/devries at rew2.2, dg at rewards 2.2-20, each at do0/do1). No regeneration is needed, for a verified reason: for ConfidNet the hyperparameter grid is the single reward 2.2, so the plain files' cross-config selection reduces to choosing a dropout slice per method and the values are unchanged; on the dev VGG13 files every ConfidNet plain row merges onto its fix-config counterpart with max absolute difference 0 (83/83 rows). Pinned protocol: score held-out ResNet18 on the existing fix-config exports restricted to `model == "confidnet"`, pairing base and variant WITHIN each (dropout, reward=2.2) slice (both slices contribute; value-identical to plain semantics per slice), Wilcoxon as in gate 1. Documented deviation from the dev pairing: the dev generator pairs only where base and variant selected the same dropout (a validation-side selection not reproducible from these exports); within-slice pairing is the value-identical replacement. Single-seed caveats: no run averaging and no checkpoint-level uncertainty on ResNet18. Protocol design used composition metadata only (model, dropout, reward row counts); no ResNet18 outcome values were read before the freeze.

**Dev-target transparency note:** because the plain files report one selected dropout per method, gate-1 pairing forms only where base and variant selected the same dropout; `n_total` therefore reflects dropout-selection agreement (e.g. VGG13 Maha n=8 means one source in agreement), not missing evaluations.

## Gate 2: FAMILY_OPERATOR adjudication (one-line justifications)

Adjudicated against the implementations in `code/src/csfs/`; the map itself lives in `spectra_campaign_harness.py`. Projection variants consume ProjectionFiltering back-projections (features) or back-projected logits, so "kept coordinates" below means the span retained by the fitted projector.

| Family | Operator | Justification (from the implementation) |
|---|---|---|
| Maha | kept | min-over-class Mahalanobis distance on back-projected features; the section 2.3 plug-in reassignment lemma applies |
| CTM | kept | max cosine between back-projected features and classifier weight rows: prototype similarity inside the kept span |
| CTMmean | kept | CTM with class-mean prototypes instead of weight rows |
| NNGuide | kept (hybrid) | kNN inner product against an energy-weighted ID feature bank, times energy; the bank proximity lives in projected feature space and carries the orientation sensitivity |
| NeCo | kept (ratio) | norm ratio of top-subspace projection to full feature: normalized-kept form, subject to the section 2.3 ratio caveats |
| PCA RecError | complement | deployed normalized residual \|h - recon\|/\|h\|; the section 2.3 inversion caveat applies for in-span shifts |
| KPCA RecError | complement | reconstruction error in kernel feature space: nonlinear complement, scoped as an analogy rather than covered by the linear theorem |
| Residual | complement | norm of the centered feature projected onto the principal complement |
| ViM | complement (hybrid) | energy minus alpha times the complement norm: the virtual logit is complement-dominant by design |
| MLS, Energy, MSR, GEN, GE, PE, PCE, REN | logit | scores of back-projected logits |
| fDBD | logit (re-adjudicated from kept) | mean normalized logit margins \|l_max - l_c\|/\|w_max - w_c\|: row-space geometry, with a scalar feature-distance normalizer |
| GradNorm | logit | last-layer gradient norm of KL to uniform: softmax-margin driven, with a feature-norm factor |
| pNML | logit | per-class regret over softmax probabilities with feature-leverage regularization |
| Confidence | logit | external confidence heads (ConfidNet/DeVries branches) |
| MahalanobisPP, NCI | out of scope | pilot families; adjudicate if and when they appear in an outcome table |

## Tier-B protocol addendum (r2-tierB, pre-registered 2026-08-08 before any orientation measurement)

Stage 2 (`measure_orientation.py` + `run_x6_orientation.sh`) reads evaluation IMAGES only, never outcome tables; dev-pool stage 2 is Tier-B calibration, held-out stage 2 runs only after the tag.

**Constants.** Batch per draw 128; 5 draws taken as disjoint consecutive blocks of the first 640 samples in deterministic loader order; ID reference = validation features (first 4000; also supplies delta_hat, the bulk variance for lam_hat, and the val-estimated class means for the NCC trial, all flagged as val-side).

**Projector convention.** Primary rank q = min(q90, k_save), where q90 is the smallest rank reaching 90 percent explained variance on the stage-1 correct-only spectrum (the pipeline's documented default threshold) and k_save = C-1+64 is what the stage-1 NPZ stores; when capped, the flag and the actually reached coverage are recorded. Secondary rank q = C-1 (class-mean scale) is recorded alongside.

**Rules (one per operator class).** Undetermined (all signs 0) when lam_hat < sqrt(D): below that even the oracle raw detector is weak. Kept: +1 iff a_hat > a*(lam_hat, q, D). Complement: +1 iff a_hat < a_flip(lam_hat, q, D). Logit: +1 iff |W P delta_hat| >= 0.8 |W delta_hat| (tolerance for estimation shrinkage of the kept response), undetermined when the displacement is classifier-invisible (|W delta_hat| below 5 percent of its maximum attainable value); row-space alignment is a diagnostic, not a rule. Variant mapping: `global` rows take the operator sign; `class` and `class pred` rows of raw-baselined families reuse the operator sign (the Tier-A class conditions hold across the dev pool); `class avg` rows are always -1 (Tier-A theory claim); PCA/KPCA RecError rows (variant-vs-global baseline) are DEFERRED to stage 2b, which requires per-class projector artifacts not extracted in stage 1.

**Trial arm (deployment-batch trial, scored alongside the rules).** Registered score set computable from stage-1 artifacts: MLS, Energy, MSR raw vs globally projected; NCC (Euclidean nearest class centroid, a labeled proxy for the deployed tied-covariance Mahalanobis); global reconstruction error in deployed-normalized and unnormalized forms (no raw counterpart). Trial signs = sign of the projected-minus-raw AUROC delta against the val reference; mapped to families {MLS, Energy, MSR, Maha(proxy)}, global variant only.

**Aggregation and scoring.** Signs aggregate by majority across draws within a checkpoint, then across the runs of a (backbone, source, dropout) group, with agreement fractions recorded. Scoring granularity is the cell: (arch, source, dropout-slice, OOD dataset, family, variant), with the cell delta rebuilt under the frozen gate-1 semantics (`score_tier_b.py`). Reported against three nulls (always +1, always -1, per-(arch, family, variant) majority), on all cells and on material cells (|delta| > 1.0 AUGRC x1000), with undetermined and deferred counts as coverage. MSR note: MSR is provably immune to common-mode logit shifts, so the shared logit rule is expected to be weakest there; per-family refinements are allowed only as a new rule version after dev calibration.

**Patch r2-tierB.1/.2 (2026-08-09, applied after the first HPC stage-2 cells ran; orientation values seen, no outcome tables touched).** Two revisions, motivated by a crash and by degenerate thresholds at real displacement scales. (1) Numerics: scipy's noncentral-F CDF has version- and parameter-dependent NaN holes at large degrees/noncentrality (crashed `a_star` on the HPC; reproduced locally at D=2048); `auc_exact` now falls back to the large-degree Gaussian approximation where the CDF is not finite, which is numerically indistinguishable from exact in those saturated regimes. The failure mode raised loudly, so completed cells were never silently corrupted. (2) Semantics: `lam_hat` is trusted only up to the ceiling where the oracle raw detector reaches AUC 0.99 (`lam_ceiling`); on real anisotropic features the isotropic estimate inflates by orders of magnitude (median coordinate variance of sparse post-ReLU features is tiny) and beyond the ceiling the exact crossings degenerate to a* = 1, freezing every kept sign at -1 regardless of orientation. Capped crossings stay discriminative (a* 0.34-0.50 across the pool's (q, D) values). Signs are recomputed from stored per-draw scalars at scoring time (`rule_signs`, shared by `tier_b` and `score_tier_b.py`), so completed orientation JSONs do not need re-measurement and every cell is scored under the same rule version.

**Dev-calibration verdict and decision r3 (2026-08-09, dev outcome tables only).** The stage-2 dev scoring (3346 cells) delivered a split verdict. The crossing-rule arm FAILED calibration: at the pre-registered q90 rank, real displacements carry 79-97 percent of their energy inside the projector (a_hat median 0.923), so both the kept and logit rules saturate into constant +1 predictors (545/545 kept cells predicted +1) against a mostly negative cell-level truth, scoring 0.17-0.42 on material cells versus a 0.685 majority null. This is saturation, not sign-inversion: orientation summaries at variance-matched rank carry no sign information on real features. The pre-registered TRIAL arm passed: 0.859 on material cells (0.758 all), consistent across families (MLS 0.91, Energy 0.90, MSR 1.00, NCC-as-Maha 0.80). Decision r3, permitted by the addendum's dev-calibration clause: the trial arm is promoted to the PRIMARY Tier-B selector for held-out scoring; the rule arm is retained as a pre-registered secondary and reported as a negative result (its saturation is itself a finding about deployment-batch orientation summaries). One rule diagnostic remained open: the kept rule recomputed at the mean-span rank q = C-1. **Resolved 2026-08-09: also saturated (545/545 predictions +1).** a_hat at rank C-1 spans 0.336-0.984 (median 0.894; per-dataset medians 0.719 tinyimagenet to 0.956 lsun cropped) against thresholds a* = 0.21-0.41, so group-majority signs never flip. The structural reading: real OOD mean displacements are never complement-dominated at either pre-registered rank; they project heavily onto the class-mean span itself, so the theory's orientation axis is not exercised by real dataset shifts, and the mostly negative kept-family deltas are driven by what the oracle model idealizes away (min-over-class scoring, estimated tied covariance, back-projection consumption, the AUGRC objective), which the trial arm measures directly. Decision r3 stands unamended: trial arm is the sole primary; the orientation-summary rules are reported as a conclusive pre-registered negative at both ranks.

## Held-out ResNet18 verdict and decision r4 (2026-08-09)

The ResNet18 round was scored under the frozen r3 protocol. Three results. (1) **Outcome replication [held-out]:** the pooled table reproduces the dev hierarchy on an unseen architecture: PCA RecError class pred +34.5 and class +33.3, Maha class pred +23.7 and global +22.3, pNML class pred +19.8, GradNorm class pred +4.0 on top; class-avg rows collapse (down to -151), and pNML global is strongly negative, all as on dev. (2) **One falsification:** Maha class avg is significantly POSITIVE (+14.7; cell-level truth 84 percent positive), breaking the Tier-A class-avg no-benefit claim for exactly one family; every other class-avg row conforms. (3) **Trial-arm decomposition:** headline material accuracy 0.500 (n=64) vs a 0.670 null, but 55 of the 64 material cells are Maha cells where the registered NCC proxy voted -1 on 37 of 55 against an 88-percent-positive truth: Euclidean nearest-centroid genuinely responds to projection differently than the deployed tied-covariance Mahalanobis on this backbone. Where the trial predicted the actual deployed score, it was 9/9 on material logit cells. The rule arms behaved as the expected negative control (still constant +1; a_hat at the mean-span rank median 0.982, the saturation finding replicating on a third architecture).

**Decision r4.** `batch_trial` now trials the actual tied-covariance min-over-class Mahalanobis (precision = pseudo-inverse of the val-estimated within-class covariance, val-side like the class means; identity-precision self-check reproduces NCC exactly). NCC is demoted to a diagnostic and no longer maps to the Maha family in scoring. **Tier bookkeeping:** because ResNet18 outcomes have been opened, ResNet18 is spent as held-out for any amended rule; the r4 calibration set is dev + ResNet18 (both re-measured under r4), and the pristine confirmation tier is the CLIP/SSL probe pools and held-out sources. Pre-r4 orientation JSONs carry no maha trial and simply produce no Maha trial predictions.

**r4 calibration outcome and patch r5 (2026-08-09).** The r4 re-measurement made the Maha trial WORSE, and diagnostically so: it became a constant-negative predictor on both calibration pools (all 55 ResNet18 material Maha cells and all 35 dev cells voted -1; ResNet18 material trial 0.250, dev 0.719, while the arm-faithful logit trials stayed excellent, 9/9 and 27/29). Root cause: r4 applied raw-space class means and precision to projected inputs, but the deployed pipeline REFITS distance families on back-projected features. Mechanism, identified and reproduced synthetically: projected inputs minus raw means carry a constant-per-class complement offset; under an ill-conditioned val-estimated precision the complement weights are enormous, those constants dominate every distance, and the projected arm's ranking degenerates toward AUROC 0.5, making the delta always strongly negative (the anisotropic self-test shows unfaithful 0.807 vs faithful 1.000; real features, with near-dead post-ReLU coordinates at D up to 2048, collapse fully). **r5:** the projected arm now uses projected-fit statistics (projected class means and the precision of the projected within-class covariance, both val-side); logit and RecError trials were already arm-faithful and are unchanged. Self-checks: per-arm identity-precision equality with NCC, and the anisotropic reproduction above. The r4 orientation JSONs are superseded (kept as `orientation_r4`); the calibration set remains dev + ResNet18 and the pristine tier remains CLIP/SSL. Lesson recorded for the paper: "trial the deployed score" includes trialing the deployed REFIT, not just the deployed formula.

## Rule version r7 (pre-registered 2026-08-10, before any r7 measurement)

Motivated by the magnitude diagnosis of the r5 round: dev Maha trials sat at an AUROC CEILING (raw 0.999, so deltas cannot resolve improvements), while ResNet18 showed a genuine directional disagreement between the batch AUROC under our reconstructed projector (raw 0.972 to global 0.806) and the deployed AUGRC truth (+22), implicating rank infidelity (our q90-capped-at-k_save rank vs the deployed BO-tuned variance threshold) and metric mismatch. r7 removes every remaining fidelity gap the campaign has identified:

1. **Deployed-projector fidelity.** Stage 2 loads the saved PF estimators per checkpoint (`{exp.dir}/params/ProjectionFiltering_{global,class}_params_RW0_RF0_ASHNone.pt`: fitted scaler means, exact PCA components, tuned `variance_explained`) and replicates `get_backprojection` verbatim, including the deployed component-count rule and the per-class estimators. This supersedes the planned stage-1b train re-forward entirely. Fallback when a params file is missing: the stage-1 projector, flagged in `pf_params`.
2. **Deployed-metric fidelity.** The primary trial statistic is a batch-level AUGRC on a 1:1 mixture of a per-draw val ID block (128 samples, failures = val misclassifications) and the OOD batch (all failures), delta = AUGRC(base) - AUGRC(variant), matching the targets' sign convention. Batch AUROC deltas are demoted to diagnostics with CEILING flags.
3. **The r6 families join the trial.** GradNorm in closed form (|C softmax - 1|_1 x |h|_1; raw, global, class-pred arms), Maha class-pred (deployed class-pred back-projection, val-side tied-covariance refit at rcond 1e-6 as deployed), and PCA RecError class-pred and class (deployed per-class back-projections, normalized score, raw-argmax routing, per-class max for `class`), scored against their family baselines (raw for GradNorm/Maha, global RecError for RecError). KPCA and class-avg variants remain untrialed.

Trial keys and baselines are frozen in `DEPLOYED_TRIAL_KEYS` (harness); scoring prefers `trial_deployed` and falls back to the legacy r5 trial per record, with the source split reported. Legacy trials are still computed for continuity. Self-checks: 54-key output, recerr_class >= recerr_cp per sample, class-pred == global when class estimators coincide, GradNorm zero at uniform logits, plus the r5 suite unchanged. Calibration remains dev + ResNet18; the CLIP/SSL tier remains pristine.

**r7 calibration verdict (2026-08-10, dev + ResNet18).** The deployed-stack trial works at scale. Aggregate material accuracy 0.755 (dev, n=229) and 0.728 (ResNet18, n=298) against 0.685/0.670 majority nulls, with coverage up 3.5-4.7x, and the aggregate UNDERSTATES the result because one family drags it: excluding Maha, 8 of 9 (family, variant) combos score 0.85-1.00 on BOTH pools. The campaign's headline rows are essentially solved: PCA RecError class pred 0.97/0.96 (dev/resnet), PCA RecError class 1.00/0.98, GradNorm class pred 0.88/0.97, GradNorm global 0.85/1.00 (the latter with 38-percent-positive truth on ResNet18, so the trial is discriminating signs, not voting a constant), logit families 0.90-1.00 including all-negative ResNet18 truths. **Maha is the isolated exception** (dev class pred 0.17, resnet global 0.22 vs 87-88 percent positive truth) and its batch-AUGRC magnitudes show the trial genuinely measuring projection as harmful (base 0.2231 vs variant 0.2422 on resnet global), with the deployed rank now loaded, so rank infidelity is excluded. Remaining candidate mechanism, flagged for r8: the ID reference block is IN-SAMPLE for the val-side Maha refits, and the D-dimensional raw refit overfits the reference more than the k-dimensional projected refit, biasing base minus variant negative; the r8 patch is statistical hygiene (split val: refit statistics on one half, ID blocks from the other), mechanism-motivated rather than outcome-tuned. Decision pending: apply r8 before the pristine tier, or proceed to CLIP/SSL with the Maha trial flagged as a known limitation.

## Rule version r8 (pre-registered 2026-08-10, before any r8 measurement)

Statistical hygiene targeting the r7 Maha residual: all val-side REFIT statistics (the r5 legacy stats and the r7 per-arm Mahalanobis sets) now use the second half of the validation set, while every ID reference (the AUROC reference sample and the per-draw AUGRC ID blocks, with their failure labels) comes from the first half, so no reference sample is in-sample for any refit. Motivation: the shared in-sample reference biases refit-based scores asymmetrically (the D-dimensional raw refit overfits the reference more than the k-dimensional projected refit, pushing base minus variant negative), which fits Maha being the only failing family in r7. Orientation statistics (delta_hat, sigma_hat) still use the full validation set: they involve no per-arm refit. The split is recorded per cell in `constants.r8_split`. Mechanism-motivated, not outcome-tuned; everything else in r7 is unchanged.

**r8 calibration verdict (2026-08-10): CALIBRATION CLOSED.** The out-of-sample reference fix recovered Maha exactly as the mechanism predicted: dev global 0.57 to 0.83, class pred 0.17 to 0.77; ResNet18 global 0.22 to 0.78, class pred 0.33 to 0.65; the dev ceiling dissolved (Maha raw batch-AUROC 0.999 to 0.837) and the ResNet18 Maha AUGRC deltas flipped to match the +22 truth. All other combos held at 0.85-1.00. Aggregate material accuracy: dev 0.869 (n=229), ResNet18 0.879 (n=298), against 0.685/0.670 majority nulls. Honest caveat kept on record: on the Maha subsets alone, whose truth runs 87-88 percent positive, a per-family always-positive oracle would still beat the trial (0.88 vs 0.65-0.83); Maha is informative but remains the weakest and most fidelity-sensitive family. r8 is the frozen trial for the pristine tier; no further calibration rounds.

## Pool A package implementation (frozen 2026-08-10, before the prediction lock; no real-feature outcome computed)

The pristine-tier design above is implemented as three scripts, all frozen before any Pool A outcome exists.

- `poola_measure.py` (predictions). Per cell: the pool's linear probe, the frozen-recipe deployed PF (probe-train correct-only fit, centering only, variance threshold 0.90, deployed component-count rule, zero-correct fallbacks), Tier-A r2 diagnostics on the correct-only and all-train arms, and the r8 deployed-stack trial (ID reference blocks and per-arm refit statistics from disjoint halves of the validation carve-out; 5 x 128 OOD draws per set; batch AUGRC primary). Cell construction is factored into `setup_cell`, verified to reproduce the measurement release exactly (records identical modulo `runtime_sec` on identical features), so outcome generation provably evaluates the locked probes and projectors.
- `poola_outcomes.py` (outcomes; refuses to run without `--locked`). Reconstructs each cell via the same `setup_cell`, fits per-arm Mahalanobis statistics on probe-train (all samples, matching the deployed mahalanobis.py, which takes no correct-only flag; arms raw / global back-projection / class-pred back-projection routed by raw-logit argmax; pinv rcond 1e-6), and writes full-test AUGRC x1000 per (cell, trial key, OOD set): mixture = full ID test set plus full OOD set, failures = probe misclassifications plus OOD membership. This is the paper's new-class convention and exactly the r8 trial's failure definition. The pinned sketch's "AUGRC via src.rc_stats" is realized by the harness's `batch_augrc`, the same empirical AUGRC estimator already registered as the r7 primary metric; this keeps outcome generation feature-space and import-light.
- `poola_score.py` (verdict). Joins predictions with outcomes on (cell, OOD set, trial key). Trial arm mirrors the frozen `score_tier_b` conventions: rows with zero true delta excluded, zero predicted sign counts as a miss, nulls always+1 / always-1 / overall majority / per-(family, variant) majority, material cut |delta| > 1. Tier-A arm is one-sided as registered: a "no-benefit" claim is falsified by a material positive outcome (delta > +1) and holds otherwise; "undetermined" makes no claim. Variant mapping: global variants score against tier_a global; class-pred variants against tier_a class pred; the RecError class variant also scores against tier_a class pred (the same per-class recoverability gate, with no routing involved). Class-avg claims have no trial keys in this pool: registered scope, reported unscored. Implemented standalone rather than as a `score_tier_b` pool entry because this pool has no checkpoint manifests, orientation JSONs, or rule arms; the scoring semantics are copied, not reinvented.
- Pre-lock amendment, recorded for transparency: an early draft of `poola_outcomes.py` restricted the ID side to correctly classified samples with failures = OOD membership only. This deviated from the registered "probe-head failures" wording and from the trial's estimand and was corrected before any lock or any real-feature outcome run.
- End-to-end validation: `poola_score.py --synthetic` runs measure -> outcomes -> score on fabricated features and asserts structural integrity only (100 percent join coverage, expected row counts, finiteness, non-degenerate predictions). Outcome values are never asserted.
